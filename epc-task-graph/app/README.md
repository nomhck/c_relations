# C-Relations

EPC工程を管理する、ブラウザ内保存型のワークスペースです。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
```

概要画面から依存関係、ガント、タスク一覧へ移動できます。新規タスクは「タスクを追加」または N。検索は Cmd/Ctrl+K。詳細パネルで所要日数を変更すると、適用前に完了日への影響が分かります。

初回の21タスクは架空のサンプルです。プロジェクトメニューから空のプロジェクトを作成できます。データはIndexedDBに保存され、端末間同期はありません。バックアップは「データ」からJSONを書き出してください。

単体テスト92件。本番ビルドで型検証を実施。PR更新時とmain更新時にGitHub Actionsでテスト・型検証・GitHub Pages向けビルドを自動確認します。E2Eシナリオは更新済みですが、この変更ではブラウザ実行は行っていません。`npm run test:e2e` はテスト専用のストア公開を有効にして検証します。本番ビルドではストアを公開しません。
